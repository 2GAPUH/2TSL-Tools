# 🧰 2TSL toolbox

Расширение для Google Chrome, которое помогает инженерам технической поддержки работать быстрее: шаблоны ответов, переходы между системами, учёт заявок, напоминания и автоматизация рутины.

## Для кого

Для сотрудников техподдержки, которые ежедневно работают в Omnichat, TTM, Argus, Axiros и смежных внутренних системах. Расширение снимает лишние клики и ручное копирование между вкладками.

---

## Возможности

| | |
|---|---|
| **Шаблоны** | Создание, группы, поиск и вставка ответов в чат Omnichat |
| **Ссылки в чате** | НЛС и номера заявок в Omnichat открывают TTM с автопоиском |
| **Переходы из TTM** | Форма ассистента (с автозаполнением), Onyma, SIPAL — одним кликом |
| **Учёт заявок** | Панель в Omnichat: закрытые, выезды, статистика, выгрузка в CSV |
| **Напоминания** | Таймеры по заявкам TTM с уведомлениями Chrome |
| **Grafana → SSH** | Клик по IP в дашборде открывает SSH-терминал с подстановкой адреса |
| **Конструктор комментариев** | Удобная сборка текста через volgahelp с возвратом в TTM |
| **Подсказка по MAC** | В EPD: при наведении на MAC — вендор и месяц производства (OUI) |
| **Тёмная тема** | Для окна расширения, Argus и Axiros (на выбор, с палитрами) |
| **Резервная копия** | Экспорт/импорт шаблонов файлом или обмен с коллегой по токену |
| **Настройки** | Каждый модуль можно включить или выключить отдельно |

---

## Как связаны системы

```
Omnichat  →  TTM (поиск по НЛС / заявке)
               ├─→ форма ассистента (автозаполнение)
               ├─→ Onyma
               └─→ SIPAL

Grafana   →  SSH-терминал (по IP)

TTM       →  конструктор комментариев (volgahelp)
```

## Установка

### Из папки (режим разработчика)

1. Склонируйте репозиторий или скачайте ZIP с GitHub.
2. Откройте `chrome://extensions/`.
3. Включите **Режим разработчика**.
4. **Загрузить распакованное расширение** → укажите папку проекта.

### Готовый архив для коллег

Если установлен [7-Zip](https://www.7-zip.org/), в корне проекта:

```bat
build.bat
```

Появится файл `dist/2TSL-toolbox-v0.8.1.zip`. Распакуйте его и загрузите как распакованное расширение (или передайте архив коллегам).

### Обновление

Скачайте новую версию / сделайте `git pull`, затем на `chrome://extensions/` нажмите **Обновить** у карточки расширения.

## Требования

- Google Chrome 110 или новее
- Доступ к внутренним системам (корпоративная сеть / VPN)
- Желательна авторизация в Chrome (для стабильной работы анонимной статистики и облачного обмена шаблонами)

---

## Конфиденциальность

- Данные шаблонов, учёта и настроек хранятся **локально** в браузере.
- Анонимная статистика использования (без email и текста переписок) можно **отключить** в настройках.
- Обратная связь из настроек отправляется отдельно, по желанию пользователя.
- Облачный обмен шаблонами по токену **не передаёт** ФИО, регион и настройки приватности.
